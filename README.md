# Доход приложений

Один сайт со всеми играми из Яндекс РСЯ, VK Рекламы и Unity Ads:

- **Сводка** — доход за месяц или период, средний доход в день и прогноз до конца месяца, вчера, eCPM и заполнение.
- **Помощник** — сам проверяет цифры и простыми словами объясняет, что сломалось или выглядит подозрительно: упал доход (и почему — меньше запросов, реклама реже заполняется или подешевела), игра перестала запрашивать рекламу, блок запрашивает рекламу без показов, VK заблокировал площадку, сеть перестала отдавать данные.
- **Приложения** — таблица всех игр: доход, доля, сколько дала каждая сеть, eCPM, заполнение. Клик по игре открывает её страницу.
- **Страница игры** — тот же разбор по одной игре: по дням, по форматам, по сетям, каждый блок отдельно. У Bottle Sort есть вкладка **«Игроки»** из Firebase: игроки по дням, время в игре, страны, уровни, кнопки «за рекламу».

Период: сегодня, вчера, 7 дней, 30 дней, этот месяц (с 1-го числа по сегодня), 90 дней или любой прошлый месяц целиком (список «Другой месяц»). Помощник при этом всегда смотрит на последние дни. Фильтр Android / iOS работает везде.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5180

Пока ключи не вписаны, на экране есть кнопка «Показать пример» — так будет выглядеть сайт с данными.

## Подключение источников

Нажмите на источник вверху страницы — там пошаговая инструкция и поле для ключа. Ключи сохраняются в файл `.env` в этой папке (JSON-ключ Google — в `secrets/`) и остаются на компьютере: страница их не видит, запросы к сетям делает сервер.

### Яндекс РСЯ

1. Откройте https://oauth.yandex.ru/authorize?response_type=token&client_id=da092e6d50b443308da7a28e638070b9 под аккаунтом с кабинетом РСЯ.
2. Скопируйте токен в `YANDEX_OAUTH_TOKEN=`.

Сайт берёт все приложения кабинета, итог совпадает с «Месячным отчётом» РСЯ. «Показы» — как в кабинете (`impressions`), а не «Видимые показы». За один запрос РСЯ отдаёт не больше 31 дня по дням — длинный период сайт сам собирает из нескольких запросов.

### VK Реклама

1. Кабинет VK Рекламной сети → «Настройки» → «Токены доступа» → токен для Reporting API.
2. Скопируйте в `VK_TOKEN=`. Все площадки и блоки сайт найдёт сам, заодно — их статус модерации.

### Unity Ads

1. Unity Cloud → Unity Ads Monetization → «Настройки» → API management → Monetization Stats API Access.
2. Скопируйте ключ в `UNITY_API_KEY=`. Все игры организации сайт найдёт сам.

Unity отдаёт запросы рекламы общим числом, без мест показа, — в подробной таблице это строка «Все форматы».

### Firebase (Google Analytics 4)

1. Firebase → проект `bottle-sort-23297` → Project settings → Integrations → Google Analytics → номер ресурса (Property ID) → в `GA4_PROPERTY_ID=`.
2. Google Cloud Console → IAM → Service Accounts → `bottle-sort-stats` → Keys → JSON. Выберите файл на сайте (окно Firebase) или сохраните как `secrets/ga-service-account.json`.
3. Google Analytics → Администратор → Управление доступом к ресурсу → email сервисного аккаунта с ролью «Читатель» (уже добавлен).
4. Чтобы работали «Уровни» и «Кнопки за рекламу», зарегистрируйте параметры событий в GA4 (Custom definitions) — список в `Docs/ANALYTICS.md` проекта игры.

## Одна игра в разных сетях — `apps.json`

В каждой сети у игры свой ID и своё название («Mahjong Panda» в Яндексе, «Panda Mahjong» в Unity). `apps.json` связывает их в одну игру:

```json
{ "name": "Bottle Sort", "firebase": true,
  "yandex": { "19370824": "Android", "20110699": "iOS" },
  "vk": { "3565161": "Android", "3565331": "iOS" },
  "unity": { "6195552": "Android", "6195553": "iOS" } }
```

Новую игру вписывать не обязательно: сайт покажет её под именем из кабинета сети и сам объединит «Игра Android» и «Игра iOS». Вписать стоит, если названия в сетях разные или нужна правильная платформа.

## На Vercel

Репозиторий подключается к Vercel (Add New → Project → этот репозиторий) — после каждого коммита сайт обновляется сам.
Сборка и функции `/api` описаны в `vercel.json`, ключей в репозитории нет.

В Vercel → Settings → Environment Variables задайте:

| Переменная | Что это |
|---|---|
| `DASHBOARD_EMAIL`, `DASHBOARD_PASSWORD` | вход на сайт; без них сайт не отдаёт данные |
| `YANDEX_OAUTH_TOKEN` | Яндекс РСЯ |
| `VK_TOKEN` | VK Реклама |
| `UNITY_API_KEY`, `UNITY_ORG_ID` | Unity Ads |
| `GA_SERVICE_ACCOUNT_JSON` | содержимое JSON-ключа сервисного аккаунта Google целиком |

После изменения переменных — Deployments → Redeploy. На Vercel ключи со страницы не сохраняются, только в настройках.

На своём компьютере вход не нужен; если задать `DASHBOARD_EMAIL` и `DASHBOARD_PASSWORD` в `.env` — будет и здесь.
